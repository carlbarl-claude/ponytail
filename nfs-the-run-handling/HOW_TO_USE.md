# 🏎️ NFS: The Run — Speed Mod — How To Use

Hi! This makes your car **keep its speed in corners** and **grip the road better**.
It's safe and you can turn it off any time. Follow these steps. 👇

---

## ⬇️ First time only (do this once)

1. Download **Cheat Engine** from **https://cheatengine.org** and install it.
   - When installing, if it asks about extra "offers" or toolbars, click **Decline** / uncheck them.
2. Put the file **`NFSTheRun_CornerSpeed.CT`** somewhere easy, like your Desktop.

That's it for setup. ✅

---

## ▶️ Every time you want to play with the mod

**Step 1.** Double-click **`NFSTheRun_CornerSpeed.CT`**.
Cheat Engine opens. If a box pops up asking *"Do you want to run the script?"*, click **Yes**.

**Step 2.** Start **Need for Speed: The Run** like normal.

**Step 3.** Play! 🏁
The mod turns on **by itself** when the game starts. You'll keep your speed in corners.

That's all you have to do. 🎉

---

## 🎮 Buttons (while playing)

You don't *need* these — the mod is already on. But if you want to switch things off/on:

| Key | What it does |
|----|----|
| **F1** | Turn **No Speed Loss** on/off |
| **F2** | Turn **Max Grip** on/off |

Press once to turn on, press again to turn off.

---

## ❓ If something's not working

- **Nothing happens in the game** → make sure you clicked **Yes** on the script box in Step 1,
  and that you opened the `.CT` file (not just Cheat Engine on its own).
- **Still stuck** → ask your brother. 🙂 Tell him: *"the mod isn't attaching"* — he'll know.

---

## 🛑 To turn the mod OFF completely

Just **close Cheat Engine** (the little window in the taskbar). The game goes back to normal.
Nothing is broken and nothing is changed forever — it only works while Cheat Engine is open.
